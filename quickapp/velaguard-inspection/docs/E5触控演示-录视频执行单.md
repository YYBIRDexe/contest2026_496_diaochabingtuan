### 1.0 ⚠️ SSH 必须带 `-i`（否则 Permission denied）

**这台 PC 没有 `~/.ssh/config`，而且默认身份（`C:\Users\Demo.01\.ssh\` 下的密钥）在设备上没被授权。**
只有一把钥匙能用：

```
F:\xiaomiaiot\runtime\credentials\id_ed25519
```

所以**裸敲 `ssh sunrise@192.168.1.104` 会报 `Permission denied (publickey,password)`** —— 不是设备坏了。
两个办法，任选：

**办法 A（推荐）· 用现成的助手脚本**：

```powershell
$VG = 'F:\xiaomiaiot\02-openvela迁移\openvela-VelaGuard快应用-20260920\tools\vg.ps1'
powershell -ExecutionPolicy Bypass -File $VG status    # 看状态
powershell -ExecutionPolicy Bypass -File $VG reset     # 复位（= 录制前必做那步）
powershell -ExecutionPolicy Bypass -File $VG shot      # 把 E5 当前画面抓到本地看图
```

**办法 B · 记住这条完整命令**：

```powershell
ssh -i F:\xiaomiaiot\runtime\credentials\id_ed25519 `
    -o UserKnownHostsFile=F:\xiaomiaiot\runtime\credentials\known_hosts `
    -o StrictHostKeyChecking=no sunrise@192.168.1.104 "命令"
```

> 下文所有 `ssh sunrise@192.168.1.104 "..."` 都请按上面两种办法之一替换。
> 脚本 `tools/vg.ps1` 里已固化这把钥匙，**纯 ASCII、PS 5.1 可直跑**（`.ps1` 里写中文会被 GBK 读坏，别再往里加中文）。

### 2.2 E5 屏与相机

| 项 | 要求 | 原因 |
|---|---|---|
| 屏朝向 | 后仰 **10–15°** | 垂直放会有反光带 |
| 屏高度 | 屏幕中心与镜头齐平（约 1.2 m 台面） | 避免俯拍变形 |
| 屏亮度 | **70–80%**，不要 100% | 满亮在镜头里偏白、丢深色层次 |
| 反光 | ⚠️ 拍前用手机预览：**屏幕上不能有窗户/灯管的倒影** | 这是最常见的废片原因 |
| 相机位置 | E5 **正前方偏右 15–20°**，与屏幕中心齐平，**不要俯拍** | 稍侧一点有立体感 |
| 取景 | E5 屏占画面宽度 **85–90%**，四边留边 | 别切掉屏的任何一边 |
| 稳定 | **必须三脚架/支架** | 全程手持必抖 |
| 对焦 | 锁定在屏幕上，**关掉自动对焦** | 手指入画时容易跑焦 |
| 曝光 | 锁定后手动压 **-0.3 ~ -0.7 EV** | 屏幕亮，不压会过曝 |
| 参数 | 1080p / 60fps / 横屏 | 手指动作更顺 |

### 2.3 手

- **食指单指**，从**画面下方或侧面**入画，**不要从上方压下来**（会挡屏）
- 点完**停 0.5 秒再收手**，让镜头看清按钮反馈
- 指甲干净、深色纯色袖口

### 2.4 车怎么放

**结论：车不进画面，或只当背景。** 因为界面里的车辆位置来自**内置路线数据**，跟真车无关 —— 车摆得再讲究，屏上也不会变。

| 方案 | 怎么放 |
|---|---|
| **A（推荐）** | 车放**画面外**，镜头只给 E5 屏 + 点按的手 |
| B | 车放**背景**，离 E5 约 1.5–2 m，画面角落，**不挡屏** |
| C | 车放**前景左下只露半车**，做纵深（有经验再用） |

选 B/C 时：车**通电但不要动**（它动了反而像作假）；车头**朝镜头侧**，别正对；**绝对不要挡住屏幕下半部分的按钮**。

## 三、拍什么：一分钟成片分镜表（照这个拍，剪的时候不用想）

总时长目标 **45–60 秒**。**先拍 ① ③ ④ ⑤（主体），有余力再补 ② ⑥。**

| 镜 | 时长 | 画面 | 你要做的操作 | 字幕（可直接抄） |
|---|---|---|---|---|
| ① 开场 | 4–6s | E5 屏全貌 + U2P 机身，能看到 HDMI / Type-C 接线 | 无（静止） | `VelaGuard 巡检调度台 · 运行在 U2P 计算板 · E5 触控屏操作` |
| ② 特写 | 3s | 只有屏幕下半部分：蓝色「开始巡检」按钮 | 无 | （无字幕） |
| ③ **主镜** | 12–14s | **手指点「开始巡检」→ 全程自动播放不切机** | **点一下，然后手完全移出画面** | 见下 |
| ④ 告警特写 | 3–4s | 屏幕上「入口大厅 [阻塞]」+ 蓝色告警浮层 | 无（可先暂停画面再靠近拍） | `1 号车遇障停车 → 任务转「阻塞」并告警` |
| ⑤ 收尾 | 4s | 巡检记录页统计 | 无 | `第 1 轮：3 已完成 / 1 阻塞` |
| ⑥ 全景 | 4s | 从侧后方拉开，E5 + U2P + 背景里待命的车 | 无 | （无字幕） |

### ③ 主镜里，9 秒内屏幕上会自动发生（**别碰屏幕**）

| 时刻 | 屏幕上会看到 |
|---|---|
| ~0.3s | 概览卡变「巡检进行中」，四个区域转「进行中」 |
| ~1.6s | 切到**巡检调度台**：四台车 + 任务清单 T-100x |
| ~2.6s | 切到**地图与路线**：真实 ROS 地图，4 台车沿路线移动，进度 40%/25%/22%/22% |
| ~3.4s | 切回调度台，**入口大厅转「阻塞」** |
| ~4.0s | 弹出蓝色告警：**「CAR-1 遇到障碍已停止，其余车辆保持原位，建议单独改派或取消。」** |
| ~9.0s | 切到**巡检记录**：`第 1 轮：入口大厅阻塞、主通道已完成、展项区已完成、设备区已完成`，统计 `3 已完成 / 1 阻塞` |

### 拍摄顺序（重要）

```
1) 复位 reset.sh，等到初始画面
2) 架好相机、锁对焦与曝光、确认取景里屏幕四边都在
3) 试拍一条：点「复位」按钮验证触控有反应 → 再跑一次 reset.sh 回到初始画面
4) 正式录：按录制 → 等 2 秒（留白给剪辑）→ 点「开始巡检」→ 手移出 → 等 9 秒 → 停在巡检记录页
5) 停录。这一条就是主镜，RAW 约 14–16 秒
6) 再补：开场全景、告警特写、收尾、车背景（各 3–6 秒，可以不同机位、分开录）
```

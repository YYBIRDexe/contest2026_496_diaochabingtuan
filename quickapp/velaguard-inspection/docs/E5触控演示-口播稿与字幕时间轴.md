## 一、口播稿（连贯版，直接念）

> 这是 VelaGuard 巡检调度台，运行在实训箱的 U2P 计算板上，通过 E5 触控屏操作。
>
> 我点一下「开始巡检」。四台车按各自区域的固定路线执行：入口大厅、主通道、展项区、设备区。
>
> 现在 1 号车在这条路线上跑到一半，遇到障碍，就地停车 —— 任务立刻转成「阻塞」，
> 界面弹出告警，并且给出改派、顺延、取消三个处置选项。
>
> 本轮结束：三个区域完成，入口大厅阻塞，记录自动归档，下一轮会优先处理未完成的区域。

**念法提示**

- 「U2P 计算板」是重点，**不要说成 openvela 或开发板**。
- 数字放慢：「四台车」「三个区域完成、一个阻塞」。
- 全程平铺直叙，不要广告腔 —— 评委听的是事实。

## 三、字幕样式

| 项 | 取值 |
|---|---|
| 位置 | 底部居中，距下边缘约 8% 画面高 |
| 字号 | 24–28（1080p 成片） |
| 颜色 | 白字 `#FFFFFF` |
| 描边/底色 | **半透明黑底** `rgba(0,0,0,0.55)` 或 2px 黑描边（深色界面不加看不清） |
| 字体 | 无衬线（思源黑体 / 微软雅黑 / 系统默认） |
| 时长 | 每条 ≥3 秒，不要一闪而过 |

## 四、尾板必须留的一句（诚实标注）

成片最后 2 秒，静止画面 + 这行字：

```
界面数据为应用内置模拟数据 · 程序逻辑为真实状态机
```

理由：界面状态栏本来就带着「模拟器演示」标签，**不要裁掉、也不要回避**。
主动写清楚，比被评委问出来强得多。

## 五、绝对不要出现在字幕/口播里的话

| ❌ 不要写 | 为什么 |
|---|---|
| 「基于 openvela 的巡检快应用」 | 跑在 U2P 的 Ubuntu 上，不是 openvela |
| 「四台真实小车正在执行任务」 | 演示不控制真车，界面位置来自内置路线数据 |
| 「实时车况 / 实时定位」 | 是内置模拟数据 |
| 「端侧 AI 决策」 | 这一段没有 LLM 参与，别硬蹭（AI 能力展示在 openvela 终端那段拍） |
| 「全自动无人巡检」 | 是演示程序，不是现场运行系统 |

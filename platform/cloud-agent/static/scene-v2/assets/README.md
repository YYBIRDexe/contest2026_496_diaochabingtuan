## 正式素材替换

`scene-config.js` 已按下面的方式接线，换图只需重复一次：

1. 把新图放进本目录；
2. 只改 `scene-config.js`：
   - `asset` 指向新图；
   - `assetVersion` 写交付日期或短哈希（同时更新 `index.html` 中 `scene-config.js?v=` 的串，否则旧配置会被缓存）；
   - `assetSize` 写实际像素宽高；
   - `assetPending` 改为 `false`；
   - 按新图重新标定 `spots` 的百分比坐标。
3. 页面会自动用新图替换 `scene-draft.svg`；加载失败时保留构图首稿并显示"正式图未加载 · 使用构图首稿"，不会回退到旧 `scene-v2.png`。

热点必须与同一个图像容器共用坐标系；`scene.js` 按 `object-fit: cover` 的实际缩放和偏移计算，换图后不要只改 viewport 百分比。

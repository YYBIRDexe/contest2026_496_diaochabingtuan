为什么可能不可用
  • Firefox 107 没有可用的网页语音识别；本页不使用 Web Speech API，也不会把猜测写成转写结果。
  • 识别必须由同源 ASR 服务或设备上的独立 ASR 入口提供；当前配置未填写端点时，只采集录音，不生成文字。
  • 如果页面响应头仍是 microphone=()，浏览器会在授权前直接拒绝录音；本样板路径已申请只对本页放开，部署后仍需实测确认。
  • 如果通过普通 http://局域网IP 打开，浏览器会把页面当作非安全上下文，同样不允许麦克风；需要 HTTPS，或在本机用 localhost 端口转发测试。

样板说明

这是场景入口，不是地图或现场证据

  • 入口与返回首页功能入口进入对应占位页。返回按钮、Escape 和浏览器后退都可用。
  • 首页入口执行异常、异常事件和巡迹地图为明确标注的占位入口。
  • 真实边界没有车控、固件或运动接口；不创建无法执行的计划，不伪造车辆、定位、水位或安全结论。
  • 聊天发送走现有 /api/chat；未配置模型时展示 503，不生成模拟回复。确认计划不等于执行。
  • 语音语音识别由设备端语音服务提供；识别文字进入现有命令处理链路。
  • 轻量动效局部水光、波纹与面板推进只用 transform/opacity；支持“静态展示”、减少动效偏好和隐藏页面暂停。
  • 键盘Tab 移动焦点，Escape 逐层返回，Ctrl/⌘ + Enter 发送。热点与主操作不小于 56px。
  • 性能采样仅地址带 ?perf=1 时显示 rAF 帧间隔采样；它是浏览器帧间隔，不是 GPU 帧率。

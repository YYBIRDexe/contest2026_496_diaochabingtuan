# static/assets

本目录只放新版控制台的静态装饰素材，不含真实现场照片。

| 文件 | 用途 | 性质 |
|---|---|---|
| `water-scene.png` | 任务中心页头右侧约 450×120 裁切装饰插画（水库/大坝/河道） | Codex built-in image_gen 生成；仅作场景示意，**不是现场照片、实时地图或检测证据**，无校徽/文字/品牌 |
| `water-lines.svg` | 工作面浅色水纹背景 | 矢量装饰，低对比度，无数据含义 |
| `water-lines-dark.svg` | 深海蓝侧栏水纹 | 矢量装饰，低对比度，无数据含义 |
| `water-dam.svg` | 备用线稿素材，当前不作为主插画或工单证据 | 本地绘制的矢量示意，**不是现场证据、不是地图、不是水位或安全状态** |

`water-scene.png` 来自 Codex《素材与样板.md》，尺寸 1774×887，页面用 `object-fit: cover` 裁到页头（桌面最大 450×120，窄屏按 380px 收敛）；页面另标“水利场景示意 · 非现场”。它不进入工单证据区，也不表示大坝真实状态。

没有使用真实照片、学校校徽、官方标识或外部版权素材。Codex 后续替换正式素材时，保留同名文件或同步修改 `index.html` / `styles.css` 即可。
